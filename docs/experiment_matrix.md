## 0. 两条不可混排的评测线

| 线 | 是否允许检索 | 参与实验 | 论文表述约束 |
|---|---|---|---|
| 闭卷 Closed-book | ❌ 禁止访问任何外部知识库 | E0、E1 | 可与 CLaw 官方模型结果直接比较 |
| 开卷 RAG | ✅ 允许查询法条向量库 | E2～E5 | 必须注明"系统在允许访问外部法律知识库的增强条件下取得的结果" |

## 1. 主实验（6 组）

| 编号 | 模型训练 | 检索系统 | 用途 | 输出目录 |
|---|---|---|---|---|
| **E0** | 原始 Qwen3-8B | 无 | 基础闭卷基线 | `outputs/closed_book/E0` |

| **E4** | QLoRA 法律微调 | 纯向量 RAG | 训练 + 检索结合 | `outputs/rag/E4` |

### 关键对比（论文主结论）

| 对比 | 回答的问题 |
|---|---|
| E0 → E1 | 领域微调是否有效 |
| E0 → E2 | 向量数据库是否有效 |
| E2 → E3 | 知识图谱与混合检索是否有效 |
| E3 → E5 | 领域微调能否在 RAG 系统上继续提升 |

## 4. 统计规范

- 每个主结果报告 **均值 ± 95% 置信区间**（Bootstrap）
- E0 vs E5 做**配对 Bootstrap 检验**，报告：平均提升、95% CI、p 值、胜/平/负案例数
- 两个 Judge 之间计算 Pearson / Spearman 相关系数
